## 게임 모드

게임을 선택하면 TAPtoTALK·TAPtoTEN과 같은 별도 시작 화면을 거칩니다. 게임 이름·아이콘·짧은 안내와 START 버튼을 표시하며, START를 눌러야 플레이가 시작됩니다. 뒤로가기는 메뉴로 돌아갑니다. 시작 화면에서는 메뉴 음악이 이어집니다.

게임 이름은 **PUZZLE / PORTRAIT / POSITION**입니다. 게임 1은 **기존 캐릭터 그림 7종 + 해피 당근 및 추가 그림 5종 + 만화 4종, 총 16종을 무작위로 제시**합니다. 기존 그림은 원래 9·12조각 구성을 유지하고 추가 그림은 3×3 정사각형 9조각을 사용합니다. 7×7 보드는 해당 그림의 정답 조각과 난이도별 오답 조각으로 채웁니다. 같은 캐릭터라도 다른 그림은 별도 퍼즐로 구분합니다. 위쪽 회색 그림에서 맞춘 구획만 컬러로 복원됩니다. 만화는 여백 없이 조금 잘라 정사각형으로 만들었으며 기존 그림은 변경하지 않았습니다. [기존 7종 복구·검증 기록](docs/research/2026-09-09-restore-original-puzzles/README.md)

게임 2의 일곱 캐릭터 순서는 같은 페이지에서 메뉴 복귀·게임 재시작을 해도 이어집니다. 일곱 명이 모두 나온 뒤 다시 섞으며 묶음 경계의 연속 중복도 막습니다. 페이지를 새로 열거나 새로고침하면 새 순서로 시작합니다.

1. **조각 찾기** — 완성 이미지를 보고 7×7 혼합 보드에서 해당 캐릭터의 모든 조각을 찾습니다. 제한시간 없이 오답 기회 5회를 제공하며 다섯 번째 오답에 Game Over와 티피 영상이 나옵니다. 빠른 완성 점수는 유지하고 45초 초과 완성은 시간에 관계없이 300점입니다.
2. **몽타주 찾기** — 2×2에서 3문제, 3×3·4×4·5×5에서 각각 5문제(총 18문제)를 맞히면 성공입니다. 5하트로 시작하며 3×3 완료 시 1하트를 회복합니다(최대 5, 보너스 저장 없음). 4×4부터 작은 얼굴 차이 위주의 오답을 사용합니다. 5×5는 6초 대기 후 블록 두 개만 문 닫기(0.36초) → 가려진 상태에서 자리 교환(0.12초) → 문 열기(0.36초)를 반복하고 나머지 23칸은 유지합니다. 문 동작 중에는 입력을 막습니다. 제한시간 없이 하트를 모두 잃으면 Game Over가 나오며, 성공·실패 모두 마지막 플레이 캐릭터의 영상을 사용합니다. 일곱 캐릭터를 한 번씩 모두 제시한 뒤 새 랜덤 순서를 만듭니다.
3. **페어 메모리** — 4×4(8쌍·1분) → 5×5(12쌍·1분) → 6×6(18쌍·1분 30초) → 7×7(24쌍·2분)을 완료하면 한 판 성공입니다. 각 단계에서 3초 미리보기 후 타이머가 새로 시작하며, 시간 초과 시 한 판이 종료됩니다. 홀수 보드 중앙은 회색 별 빈칸입니다. 일곱 멤버의 원본 얼굴만 반복 사용하고 바리에이션은 제외합니다. 같은 얼굴 두 장이면 원래 쌍과 무관하게 정답입니다.

## 이미지 구성

- 게임 1·2는 하트 5개로 생명을 표시하며, 오답 시 회색 하트·약한 흔들림·짧은 빨간 테두리 경고를 표시합니다. 동작 줄이기 설정에서는 흔들림을 생략합니다.

- Git에 보관된 `게임3` 폴더의 표정 바리에이션은 보류 중이며 현재 게임에서 사용하지 않습니다.

- 캐릭터 폴더: `Bb`, `Ha`, `Hoo`, `Ja`, `Pino`, `Tapee`, `Tepee`
- PNG: 위쪽에 제시하는 완성 이미지
- JPG: 보드와 메모리 카드에 사용하는 이미지 조각. 파일 번호 순서대로 왼쪽 위부터 가로 방향으로 채웁니다.
- 9장은 `1–3 / 4–6 / 7–9`의 3×3, 12장은 `1–3 / 4–6 / 7–9 / 10–12`의 3×4입니다.
- `Tapee`는 완성 PNG가 없으므로 JPG 12장을 3×4로 조립해 목표 이미지를 표시합니다.
- 게임 2는 해피·뽀글스·태피·티피·후피·재피·피노팬의 얼굴 정답과 제공된 바리에이션을 사용합니다. 최적화 파일은 `optimized/montage/` 아래 캐릭터별 폴더에 둡니다.
- 게임 2의 뒷모습 6개와 상하 반전 2개는 모든 단계에서 제외합니다(원본 파일은 보관). 첫 2×2의 오답은 색상 변경 대신 얼굴·장식의 형태 변화로 구성합니다.
