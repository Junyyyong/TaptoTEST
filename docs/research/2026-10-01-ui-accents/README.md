# 흰 기본 UI 유지와 기존 강조색 복원

2026-10-01 사용자 피드백에 따라 배경·기본 박스는 흰색/연한 회색으로 유지하고, 중요 동작과 기록을 강조하던 기존 색/그라데이션을 복원했다. 전체 UI를 회색으로 만들었던 [직전 작업](../2026-10-01-neutral-ui/README.md)을 부분 수정한 것이다.

[780×1688 PNG 전후 비교 갤러리](index.html)

후속 확인에서 빠져 있던 **메인 Settings·PORTRAIT 단계 표시·Retry**의 색도 복원했다. 갤러리의 변경 후 이미지는 이 보완까지 포함한 최신 화면이며, 첫 검증과 캡처는 `final/`에 보존했다. 아래 추가 확인에 문제와 검증 내용을 기록했다.

이후 사용자 승인으로 이 소스를 포함한 **1.0.4/code6 서명 AAB를 생성했다**. 아래 ‘AAB 생성·push 없음’은 화면 수정·검사 당시의 상태이며, 최종 파일 정보·출시노트·빌드 검증은 [업데이트 기록](../2026-10-01-ui-release/README.md)에서 확인한다.

## 복원한 강조 요소

| 요청 | 변경 후 |
| --- | --- |
| 스튜디오 로고 배경 | 기존 노란색 `#fccf00` |
| START 화면 아이콘·게임명·버튼 | 파란 아이콘, 주황 제목, 초록 START의 기존 그라데이션·입체 효과 |
| 게임 선택 화면의 게임명 | 기존 파란색. 세 게임명에 같은 스타일 적용 |
| 일시정지 Resume·Main menu·Music Off | 초록 Resume, 주황 링크 |
| 결과 시간·아래 버튼·BEST 배경 | 파란 현재 기록, 초록 Play again, 주황 Home, 기록 경신 시 기존 금색 반투명 BEST 배경. NEW BEST도 주황색 복원 |
| POSITION 제시 쌍 수 0/2 | 기존 주황색 |
| 진행 게이지 | 기존 노랑→주황 그라데이션 |
| SETTINGS 상단 제목 | 기존 주황색 |
| on/off 스위치 | 기존 꺼짐 색, 초록 켜짐 그라데이션과 손잡이 효과 |

전체 배경, 게임 선택 박스, 뒤로가기/일시정지 원형 버튼, 팝업 바탕, 설정 항목 박스는 중립적인 흰색·회색 스타일로 남겼다. 로고 원본과 CSS 그림자 제거도 유지했다.

서체·글자 크기·굵기·행간·버튼 크기·위치·비율, 게임 블록/카드/이미지와 정답·오답·안내 효과, 게임 규칙·기록·패키지명·안전영역 및 화면 비율 기능은 바꾸지 않았다.

## 수정과 검증

실행 소스는 `title.css`에서 스튜디오 배경과 메뉴 게임명 색을 복원하고, `neutralUi.css`에서 강조 요소를 회색으로 덮던 선언을 제거했다. 일시정지/결과 링크의 기존 색만 명시했다. 원래 강조 CSS를 재사용해 새 색·효과를 임의로 만들지 않았다.

- `npm test`: **35개 파일, 348개 테스트 통과**.
- `npm run build`: TypeScript 검사와 production build 성공.
- 전후 **15개 화면**의 좌표·크기·서체·행간·간격과 게임 요소의 색/효과가 동일함을 확인했다. 좌표/크기는 0.1 CSS px 미만 허용 오차로 비교했다.
- 첫 회색 변경 전에 저장한 검증 데이터와 강조 요소를 비교했다. 14개 화면/선택자 조합의 원래 색·그라데이션·그림자 및 제목·링크·켜짐 스위치 색을 확인했다.
- 로고·캐릭터·폰트·음원·영상 등 에셋 **415개가 바이트 단위로 동일**하다. 파일명 해시 참조만 정규화한 JavaScript 실행 내용도 동일하다.
- `git diff --check` 통과. [상세 검증 JSON](final/verification.json)

재현: 먼저 현재 소스를 빌드하고, `NEUTRAL_ACCENTS=1`과 수정 전 정적 빌드 경로 `BASELINE_WEB`, 새 출력 폴더 `NEUTRAL_REPORT_DIR`를 지정해 `node tests/browser/neutral-ui.cjs`를 실행한다. 이전 캡처 폴더는 덮어쓰지 않는다.

## 캡처와 배포 범위

변경 전은 직전의 흰색/회색 UI이며, 변경 후는 강조색을 복원한 UI다. PNG **30장 모두 780×1688px**이며 Chrome 390×844 CSS viewport를 2배로 촬영했다. 동일한 무작위 시드와 별도 테스트 저장소를 사용했고, 비교용 애니메이션 시점을 맞췄다. 결과창 시간은 자동 입력으로 만든 검사 기록이다.

연구기록과 갤러리는 게임에서 불러오지 않는다. 다른 게임 저장소·Android 패키지·서명 키는 수정하지 않았다. 실제 기기 검증은 별도이며 **AAB 재생성·commit·push·스토어 업로드는 하지 않았다.** 기존 AAB에는 이번 소스 수정이 아직 포함되지 않는다.

## 누락된 강조색 추가 확인

메인 화면 맨 아래 Settings가 회색으로 남아 있었다. 일반 텍스트 버튼의 회색 스타일을 일시정지와 결과창에서만 제외했기 때문이다. 활성 화면의 다른 강조 요소도 기존 CSS와 비교해 다음 세 곳을 보완했다.

| 요소 | 문제 | 수정 |
| --- | --- | --- |
| 메인 Settings | 일반 텍스트 버튼 색에 덮여 회색으로 표시 | 기존 `--hot-deep` 주황색. 크기·위치·밑줄 유지 |
| PORTRAIT 하단 STAGE | 일반 글자와 같은 회색으로 덮임 | 원래 `--hot` 주황색을 그대로 사용 |
| 저장 오류 Retry | 초록 동작 버튼까지 일반 회색 박스로 덮임 | 원래 `--go` 초록 바탕·흰 글자. 안내 박스는 연한 회색 유지 |

START 아이콘·제목·버튼, 메뉴 게임명, Resume·Main menu·Music Off, 결과 기록·NEW BEST·BEST 배경·Play again·Home, POSITION 쌍 수, 진행 게이지, SETTINGS 제목과 스위치도 다시 확인했다. 일반 설명·캐릭터 이름·Privacy policy와 Licenses 링크·문서 닫기 등 기본 UI는 승인된 회색 스타일을 유지했다. 보관용 튜토리얼 및 원본 TALK 게임 모듈은 수정하지 않았다.

- `npm test`: **35개 파일, 349개 테스트 통과**. 세 누락 요소를 회색으로 덮지 않는 회귀 테스트를 추가했다.
- `npm run build` 및 `git diff --check` 통과.
- 추가 전후 **16개 화면·32장 PNG**를 780×1688px로 저장했다. 앞선 15개 화면에 저장 재시도 UI의 모의 표시를 추가했으며, 실제 저장 오류를 발생시키거나 데이터를 초기화하지 않았다.
- 16개 화면의 좌표·크기·서체·간격 및 게임 색·효과가 동일했다. 로고·이미지·폰트·음원·영상 에셋 415개와 해시 참조를 정규화한 JavaScript 실행 내용도 동일했다. 브라우저 오류는 없었다.
