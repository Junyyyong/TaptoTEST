# 공개 명칭을 TAPtoTEST로 통일

2026-09-30 KST. 기준 커밋 `462dfd723b0c0b8492439aaef4d293bc200df951`.

## 문제와 수정

개인정보처리방침에 예전 이름을 설명하는 문구와 이전 Android 패키지 ID가 남아 있었다. 현재 앱만 안내하도록 영어·한국어의 이전 이름 괄호 설명을 제거하고 패키지 설명도 현재 `io.github.junyyyong.taptotest`만 표시한다. 다른 앱·도메인의 데이터가 자동 이전되지 않는다는 정보는 유지한다.

커버의 접근성 이름·대체 텍스트 및 메인 로고 대체 텍스트도 `TAPtoTEST`로 맞췄다. 라이선스는 이미 현 명칭만 쓰고 있어 제3자 라이선스 원문을 수정하지 않았다.

기존 기록 유지를 위해 내부 저장 키·코드 식별자·에셋 파일 경로는 변경하지 않는다. 과거 연구기록은 당시 상태를 나타내므로 덮어쓰지 않는다. 게임 규칙·이미지·앱 ID·권한·서명은 변경하지 않았다.

- `npm test`: 31개 파일, **327개 테스트 통과**. 공개 정책/라이선스에 이전 명칭이 없고 접근성 이름이 현 명칭인지를 검사하는 테스트 3개 추가.
- `npm run cap:sync`: 타입 검사·프로덕션 빌드·Android 동봉 문서 갱신 통과.
