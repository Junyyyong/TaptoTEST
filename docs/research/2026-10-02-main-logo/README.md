# 메인 로고 실제 표시 폭 통일 — 2026-10-02

## 문제와 수정

TEST는 이미지 박스 너비 상한만 적용해 모바일에서 로고가 TALK보다 크게 보였다. TALK는 너비 상한과 함께 로고 영역 높이에서 KOREAN 표시용 24px을 뺀 높이 제한도 적용한다.

두 원본 이미지의 알파 경계를 측정했다. TEST 990×957, TALK 3603×3146이며 모두 실제 그림이 이미지의 좌우 끝까지 닿으므로 가로 투명 여백 보정값은 1이다. TALK의 **실제 표시 폭**을 산출해 TEST에 적용하고, TEST 이미지 자체와 원본 비율은 유지했다. 기존 로고 배치 공간을 보존해 중심점·메뉴 버튼·Settings·음악 안내는 움직이지 않는다. 스튜디오 로고와 커버는 변경하지 않았다. 참고 저장소에는 파일을 쓰거나 빌드하지 않았다.

## 검증

- `npm run build` 통과.
- `tests/browser/main-logo.cjs`: 웹·Android 시뮬레이션 각각 일반/짧은/작은 모바일·세로/가로 태블릿, 총 10개 조건 통과. 실제 로고 가로폭 차이 0.03px 이내, 이미지 비율·경로·해시·중심 위치·나머지 메인 UI 위치와 크기 유지.
- 전체 Vitest: 356개 통과, 기존 릴리스 버전 검사 1개 실패. `tests/android-release.test.ts`가 아직 versionCode 6 / 1.0.4를 기대하지만 현재 Android 설정은 이미 versionCode 7 / 1.0.5이다. 이번 로고 변경과 무관해 해당 테스트와 Android 버전은 수정하지 않았다.
- 실제 기기 테스트나 AAB 생성·push는 하지 않았다.

측정 원본: [이전](baseline.json), [수정 후](after.json). 재현 스크립트는 비교 전 `LOGO_PHASE=baseline`, 빌드 후 `LOGO_PHASE=after`로 실행하며 기존 캡처를 덮어쓰지 않는다.
